# Security Policy

## Supported versions

Only the latest release of each plugin is maintained and receives fixes.

## Reporting a vulnerability

Please **do not report security vulnerabilities through public GitHub issues**.

Instead, report them privately via GitHub's
[private vulnerability reporting](https://github.com/svierk/salesforce-skills/security/advisories/new)
("Report a vulnerability" under the repository's **Security** tab).

Relevant here is anything that could make an agent following a skill act against its user - for example
instructions that expose credentials, weaken a pipeline's security settings, or run destructive commands
without confirmation. Please include the plugin and version, the request that leads there, and the impact.

You can expect an initial response within a few days. Once the issue is confirmed, a fix will be released as
quickly as is reasonable, and your contribution will be credited unless you prefer to remain anonymous.
